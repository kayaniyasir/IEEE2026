Task
Given a sorted nondecreasing integer array and Q query values X, print the 1-indexed first and last positions where X occurs. If absent, print -1 -1.

Input
N Q; N sorted integers; Q query values (one per line or whitespace-separated).

Output
For each query, 'first last' using 1-based indexing, or -1 -1.

Constraints
1<=N,Q<=100,000; each array value and query within +/-10^9.

HOW TO SOLVE THE QUESTION
1. Read N and Q, then the N integers, already sorted in nondecreasing order. Do not reorder the original positions.

2. For query x, binary search lower_bound: the first index i where A[i]>=x. Maintain half-open interval [left,right).

3. If i==N or A[i]!=x, the answer is -1 -1.

4. Otherwise use upper_bound: first index j where A[j]>x, which is one past the final matching Java index.

5. Print i+1 as the first 1-based position and j as the last 1-based position. Repeat for all Q queries.

WHY THE ALGORITHM WORKS
In a sorted array all occurrences of one value form a single block. Two binary searches find its boundaries in O(log N) even if there are many duplicates.

SAMPLE TRACE
For A=[2,4,4,4,5,8,10,12], x=4: lower bound index 1, upper bound index 4, output 2 4. For x=11, the lower bound points at 12, so print -1 -1.

COMPLEXITY TARGET
O(N+Qlog N) time and O(N) memory.
