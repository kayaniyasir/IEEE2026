THE TWIN OCCURRENCE QUEST — PROGRESSIVE HINTS

HINT 1: CONCEPT
In a sorted array all occurrences of one value form a single block. Two binary searches find its boundaries in O(log N) even if there are many duplicates.

HINT 2: ALGORITHM
Read N and Q, then the N integers, already sorted in nondecreasing order. Do not reorder the original positions.
For query x, binary search lower_bound: the first index i where A[i]>=x. Maintain half-open interval [left,right).

HINT 3: JAVA IMPLEMENTATION
If i==N or A[i]!=x, the answer is -1 -1.
Otherwise use upper_bound: first index j where A[j]>x, which is one past the final matching Java index.
Print i+1 as the first 1-based position and j as the last 1-based position. Repeat for all Q queries.

CONCEPT QUESTIONS
1. What is the key invariant of the algorithm?
2. Why does the algorithm terminate and produce the right answer?
3. Which small counterexample would catch a common mistake?
