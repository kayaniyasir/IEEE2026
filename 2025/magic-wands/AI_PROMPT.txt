Task
For each string S of H (happy) and S (sad), a magic wand flips the mood of exactly K consecutive characters. Determine the smallest number of operations to make every character H; print -1 if impossible.

Input
T test cases; for each case N K and a length-N string of H and S.

Output
One minimum-operation count per case, or -1.

Constraints
N,K<=100,000; the sum of N over all test cases <=200,000.

Test input

4
3 2 SSH
3 2 HHH
3 2 SHS
1 1 S


Test output

1
0
2
1

========== END OF QUESTION ==========

HOW TO SOLVE THE QUESTION
1. Read T, then N,K and the H/S string for each test case.

2. Process positions left to right. Once you arrive at index i, no flip started later can affect that position, so any sad effective state MUST be fixed now.

3. Track active flips by their parity (even means current mood unchanged, odd means inverted).

4. When an unhappy position is encountered, start a K-long flip there if i+K<=N; toggle active parity and record the expiration at position i+K.

5. If a sad position cannot fit a new K-long flip, print -1. Otherwise the number of flips is the minimum.

WHY THE ALGORITHM WORKS
The first sad effective position forces the leftmost possible flip. All other decisions would leave that position unfixed. Parity and expiry events simulate range flips in linear time, rather than modifying K characters per flip.

SAMPLE TRACE
With K=2 and SHS, flip the first two positions: SHS -> HSS. Flip positions two and three: HSS -> HHH. Minimum 2. SSH needs only one flip, and HHH needs zero.

COMPLEXITY TARGET
O(sum N) time and O(max N) auxiliary memory.
