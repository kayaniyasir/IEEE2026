Task
On an N x M integer grid, move up/down/left/right (never diagonally), always to a strictly greater value. Find the maximum number of cells in any valid increasing path.

Input
N M, followed by N rows of M integers.

Output
One integer: the maximum path length.

Constraints

Test input

7 8 9


Test output

HOW TO SOLVE THE QUESTION
1. Treat each matrix cell as a vertex and allow directed moves only to strictly greater up/down/left/right neighbors.

2. Count, for each cell, its strictly GREATER neighbors. These counts are its number of unprocessed successors in the increasing-path graph.

3. Initialize dp[cell]=1 and put all local maxima (greater count zero) in a queue.

4. Pop a maximum cell u. For each adjacent strictly smaller cell v, set dp[v]=max(dp[v],1+dp[u]). Decrease its greater-neighbor count and enqueue v when the count becomes zero.

5. Return the largest dp value. Processing in reverse topological order avoids deep recursion and correctly computes increasing paths viewed from each start.

WHY THE ALGORITHM WORKS
The strict inequality makes the move graph acyclic. Reverse topological DP aggregates path lengths from larger neighbors before a smaller cell is finalized, so every valid increasing path is considered once.

SAMPLE TRACE
A 3×3 snake: 1 2 3 / 6 5 4 / 7 8 9. Valid steps 1→2→3→4→5→6→7→8→9 traverse neighboring cells. The best length is 9.

COMPLEXITY TARGET
O(N*M) time and O(N*M) memory, since each cell has at most four adjacent cells.
