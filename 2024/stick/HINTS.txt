CONCEPT HINT
The translation pattern makes each successive square add the same net uncovered portion. Counting one full square plus N-1 additions avoids enumerating geometric coordinates.

ALGORITHM HINT
Each of the N equal squares has side length 2L, so one area is 4L².
The displacement between adjacent squares is K in both x and y. Their overlap has side max(0,2L-K), hence area overlapSide².

IMPLEMENTATION HINT
Each square after the first adds oneSquareArea-overlapArea of new area because its intersections with still older squares are contained within the preceding overlap.
Total area = N*(2L)² - (N-1)*(max(0,2L-K))².
Use BigInteger operations in Java 17 if arbitrary large values are possible, and print only the final integer.
