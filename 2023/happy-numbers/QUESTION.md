# Happy Numbers — IEEEXtreme 17.0 (2023)

**Original paraphrase based on an authentic problem archive.** [View archived contest PDF](https://github.com/kmishmael/IEEEXtreme-17.0/blob/main/Happy%20Numbers/happy%20numbers.pdf).

## Task
Count happy integers in a closed range. A happy number repeatedly replaces itself by the sum of the squares of its digits and eventually reaches 1.

## Input
Two decimal integers L R, representing one range, as in the archived team solution.

## Output
Number of happy integers in the interval. This teaching implementation uses modulo 1,000,000,007; check the original output specification.

## Sample input (independently created test)
```text
1 1000
```

## Expected output
```text
143
```
