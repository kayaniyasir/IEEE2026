# Restaurant Cipher — IEEEXtreme 17.0 (2023)

**Original paraphrase based on an authentic problem archive.** [View archived contest PDF](https://github.com/kmishmael/IEEEXtreme-17.0/blob/main/Restaurant%20Cipher/restaurant%20cipher.pdf).

## Task
For each text line, count A through G (case-insensitive) and report the most frequent letter; break ties alphabetically.

## Input
First line T, then T text lines.

## Output
One uppercase letter per line.

## Sample input (independently created test)
```text
3
AABb!
cCdD
gggA
```

## Expected output
```text
A
C
G
```
