The sample is an independently constructed teaching case, not claimed as an official sample.

Also test: minimum bounds, ties or repeated values, invalid/absent cases where defined, and a large valid input. The community archive contains an original contest PDF, but its complete constraints and tie rules have not been independently verified.

TESTING PROCEDURE
1. Compile: javac Main.java
2. Run: java Main < sample.in
3. Compare exactly with sample.out, ignoring at most the final newline.
4. Create at least five independently reasoned extra tests for:
   1) Counting letters H-Z too
   2) Ignoring lowercase input
   3) Using >= and accidentally selecting the later tied letter
   4) Reading a line token by token
   5) Assuming the no-valid-letter behavior is official
5. Never infer official judge acceptance from these local checks.

SOURCE WARNING
2023 original contest PDF exists but its tie rule, bounds, and empty/no-A-G behavior remain unverified. This is the repository practice interpretation.
