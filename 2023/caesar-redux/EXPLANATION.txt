CAESAR REDUX — DETAILED JAVA SOLUTION EXPLANATION

1. WHAT THE PROBLEM MEANS
Apply a Caesar shift to each lowercase sentence. A published team's educational interpretation uses a backward shift when the exact token 'the' appears, forward otherwise.

2. REASONING — WHY THIS APPROACH
Encoding a letter as a number 0..25 turns rotation into modular arithmetic, allowing wraparound in O(1) work per character.

3. ALGORITHM STEP BY STEP
1) Read T; for each case read the shift as a whole line and the sentence as a whole line.

2) The repository practice rule uses a backward shift only when the exact space-separated token 'the' is present; otherwise use a forward shift.

3) Compute delta with Math.floorMod(direction*shift,26), so large and negative shifts still wrap around correctly.

4) For each lowercase a-z, convert to index 0-25, add delta modulo 26, and convert back; preserve all other characters.

5) Print one transformed line per case; do not add prompts or debugging output.

4. WORKED EXAMPLE
For shift 3 and 'the cat', the exact token 'the' occurs, so shift backward: t->q, h->e, e->b; c->z, a->x, t->q. Output 'qeb zxq'. For 'abc xyz', shift forward to 'def abc'.

6. COMPLEXITY
